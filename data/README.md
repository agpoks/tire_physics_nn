# data/

- `raw/` — untouched downloads. Not committed.
- `processed/` — canonical-schema Parquet/CSV produced by the adapters in `tire_nn/data/`. Not committed.
- `public/` — extracted public datasets produced by `scripts/download_*.py`. Not committed.

Canonical column schema, units and sign conventions: **PLAN.md §4**.

## Source types — always labelled

Every dataset used or documented here carries one of these labels, and the label is repeated
in any results table that uses it:

| label | meaning |
|---|---|
| **real measurement** | physical test bench or instrumented vehicle |
| **simulated** | generated by a vehicle-dynamics simulator |
| **game telemetry** | racing-game UDP/telemetry logs — illustrative only, excluded from quantitative claims |
| **synthetic** | generated in this repository (Magic Formula, relaxation, graining models) |
